## 1. Stack Tecnologico

### Core / Framework principal

| Tecnologia     |   Version | Uso dentro del proyecto                                                                                               |
| -------------- | --------: | --------------------------------------------------------------------------------------------------------------------- |
| **Astro**      |  `^7.2.6` | Framework principal del portafolio. Generacion estatica del sitio mediante SSG y composicion de componentes `.astro`. |
| **React**      | `^19.2.8` | Componentes interactivos aislados e iconos SVG reutilizables.                                                         |
| **React DOM**  | `^19.2.8` | Renderizado de componentes React integrados con Astro.                                                                |
| **TypeScript** |  `^5.9.0` | Tipado estatico, contratos de datos, utilidades y componentes React/TSX.                                              |

### Estilos y sistema visual

| Tecnologia                |             Version | Uso dentro del proyecto                                                       |
| ------------------------- | ------------------: | ----------------------------------------------------------------------------- |
| **Tailwind CSS**          |            `^4.3.3` | Sistema principal de estilos utility-first y diseño Mobile-First.             |
| **@tailwindcss/vite**     |            `^4.3.3` | Integracion de Tailwind CSS con el pipeline de Vite/Astro.                    |
| **CSS Custom Properties** |              Nativo | Tokens semanticos para colores, superficies, textos, bordes, acentos y temas. |
| **Inter**                 | Sistema tipografico | Fuente principal de interfaz mediante la familia `font-sans`.                 |
| **JetBrains Mono**        | Sistema tipografico | Fuente monoespaciada para elementos técnicos o de codigo.                     |

### Animaciones e interaccion

| Tecnologia        |   Version | Uso dentro del proyecto                                                 |
| ----------------- | --------: | ----------------------------------------------------------------------- |
| **Framer Motion** | `^13.1.1` | Microinteracciones, transiciones, animaciones de tarjetas y menú movil. |
| **Lucide React**  | `^1.34.0` | Iconografia de interfaz para navegacion, acciones, enlaces y controles. |
